# 项目企划：面向双打与《宝可梦：冠军》的智能对战分析系统

## 一句话介绍

我们希望构建一个面向宝可梦双打对战与未来《宝可梦：冠军》规则环境的智能对战分析系统：底层复现对战规则与回合结算，上层结合机器学习、博弈论和玩家风格建模，帮助玩家进行对局推理、赛后复盘、配队优化和胜率评估。

## 项目愿景

宝可梦对战表面上是游戏，实际上是一个非常复杂的策略决策问题。它同时包含：

- 不完全信息：对方的努力值、道具、招式、太晶属性并不完全可见
- 随机性：命中、伤害随机数、急所、追加效果等
- 同时行动：双方在每回合同时选择行动
- 多回合博弈：当前回合的选择会影响后续速度线、资源、站位和胜利条件
- 玩家心理：读换、反读、守住、集火、冒险翻盘、优势保守等
- 队伍构筑：配队本身会决定对局上限、容错率和环境适应性

因此，这个项目不只是一个“查属性克制”的小工具，而是希望探索：

> 能否用规则模拟、机器学习和博弈论，构建一个可以解释宝可梦对战决策的智能助手？

长期目标是让系统能够回答类似问题：

```text
当前双打局面下，我应该集火、守住、换人，还是控速？
如果对方是激进型玩家，我该如何调整策略？
这支队伍面对当前环境主流队伍胜率如何？
这场 replay 中真正的转折点在哪一回合？
在《宝可梦：冠军》规则下，哪些构筑更稳定？
```

## 为什么这个项目值得做

### 1. 研究价值

这个项目天然连接多个重要研究方向：

```text
- 强化学习 Reinforcement Learning
- 多智能体博弈 Multi-Agent Decision Making
- 不完全信息博弈 Imperfect Information Game
- 贝叶斯推断与 Belief State
- 博弈树搜索与 Monte Carlo Tree Search
- 玩家行为建模 Opponent Modeling
- 序列数据建模 Replay / Timeline Modeling
- 可解释 AI Explainable AI
```

相比传统棋类游戏，宝可梦对战有更多现实世界决策问题的特点：隐藏信息、随机性、资源管理、心理预判、风格差异和非完全理性玩家。它是一个非常适合作为教学、科研和工程实践结合的策略 AI 课题。

### 2. 工程价值

项目可以拆分成多个清晰模块，适合多人协作：

```text
- 对战规则引擎
- 本地图鉴数据与规则集管理
- 双打回合模拟器
- Replay 时间轴与复盘系统
- 博弈树与胜率评估
- 玩家风格模型
- 配队推荐模块
- CLI / Web / Bot 交互界面
```

每个模块都可以独立推进，也可以作为课程项目、毕业设计、科研训练或开源项目的一部分。

### 3. 实际应用价值

《宝可梦：冠军》被定位为更强调对战的平台，未来可能带来新的规则、数值体系和竞技环境。提前构建一个支持规则快照、版本适配和双打优先的分析系统，具有实际应用价值。

项目可以服务于：

```text
- 宝可梦对战玩家学习
- 队伍构筑辅助
- 对战复盘分析
- 对局策略训练
- AI bot 研究
- 游戏 AI 课程案例
```

## 项目核心目标

本项目计划分成两层：

```text
第一层：Battle Model 宝可梦对战模型
第二层：Game Theory Model 宝可梦对战博弈模型
```

### 第一层：Battle Model

目标是回答：

> 在给定规则和局面下，对战会如何结算？

需要支持：

```text
- 宝可梦基础数据：种族值、属性、招式、特性、道具、可学习技能
- 规则集：历代规则、双打规则、《宝可梦：冠军》规则、赛季规则
- 战斗状态：场上宝可梦、后备、HP、异常、能力变化、天气、场地等
- 回合模拟：行动顺序、目标选择、伤害计算、随机数、胜负判定
- 特殊机制：Mega、Z 招式、极巨化、太晶化，以及未来冠军规则
- 事件日志：每回合发生了什么，可用于复盘和机器学习数据构造
```

### 第二层：Game Theory Model

目标是回答：

> 在隐藏信息、玩家风格和多回合博弈下，应该如何决策？

需要支持：

```text
- 局部博弈树生成
- 胜率评估
- 对方行动预测
- 玩家风格建模
- 风险偏好与心理压力建模
- Belief State 隐藏信息推断
- Replay 复盘与关键回合识别
- 配队推荐与 matchup 分析
```

## 项目特色

### 1. 双打优先

本项目将重点放在双打对战，而不是单打。

双打有更丰富的策略结构：

```text
- 双方各两个行动的联合决策
- 集火与分散攻击
- Protect / 守住博弈
- 控速：顺风、戏法空间、电磁波、冰冻之风等
- 站位与换人
- 辅助招式与队友协同
- 范围招式收益
```

这使它更适合研究多智能体决策和博弈论。

### 2. 面向《宝可梦：冠军》

项目将从架构上支持《宝可梦：冠军》规则：

```text
- 独立 champions 规则族
- 赛季化规则快照
- 补丁化数据更新
- 不假设其完全等同于传统主系列规则
```

这样即使未来 Gen 10 或《宝可梦：冠军》规则发生变化，系统也可以通过规则适配层扩展，而不是推倒重写。

### 3. 玩家风格与心理博弈

系统不只计算“理论最优操作”，还会考虑真实玩家风格：

```text
- 保守型玩家
- 激进型玩家
- 喜欢读换的玩家
- 容易在劣势时冒险的玩家
- 抗压能力强或弱的玩家
- 偏好 Protect、集火或控速的双打玩家
```

在同一个局面下，面对不同玩家，系统可能给出不同建议。

### 4. 可解释 AI

输出不只是一个胜率数字，而是解释：

```text
为什么推荐这个行动？
它的收益是什么？
风险是什么？
如果对方守住怎么办？
如果对方换人怎么办？
这个操作适合稳健玩家还是激进玩家？
```

这让项目不仅适合竞技辅助，也适合教学和科研展示。

## 技术路线

### 阶段 0：顶层架构确认

目标：确定项目边界和长期设计。

任务：

```text
- 确认双打优先、冠军优先
- 确认 Battle Model / Game Theory Model 边界
- 确认数据源策略
- 确认规则集快照方式
- 确认第一版 MVP 范围
```

### 阶段 1：本地图鉴与规则数据

目标：建立本地标准化数据层。

任务：

```text
- Species / Move / Ability / Item / Learnset 数据模型
- 属性克制表
- 招式基础数据
- 规则集描述格式
- champions experimental 规则占位
```

### 阶段 2：双打回合模拟 MVP

目标：实现最小可运行的双打对战模型。

任务：

```text
- 双方各 2 只场上宝可梦
- 行动选择：出招、换人、守住
- 目标选择
- 速度顺序
- 基础伤害估算
- 事件日志输出
```

### 阶段 3：Replay / Timeline

目标：支持对战记录复盘。

任务：

```text
- BattleRecord 数据结构
- state_at(turn)
- events_at(turn)
- diff_between(turn_a, turn_b)
- 关键回合标记
```

### 阶段 4：局部博弈树

目标：在某一局面下展开双方可能行动。

任务：

```text
- JointAction 生成
- 行动剪枝
- Payoff Matrix
- 1-2 回合局部搜索
- 稳健解 / 激进解 / 风险解释
```

### 阶段 5：机器学习原型

目标：从 replay 或模拟数据中学习策略和胜率。

任务：

```text
- Policy Model：预测行动分布
- Value Model：预测局面胜率
- 基础特征工程
- 训练 / 验证 / 测试流程
- 模型校准和评估
```

### 阶段 6：玩家风格与配队推荐

目标：让系统更接近真实对战教练。

任务：

```text
- PlayerProfile 风格模板
- 风险偏好效用函数
- 对手行动概率修正
- 队伍弱点分析
- matchup 胜率估计
- 根据玩家风格推荐队伍
```

## 对教授可能有价值的研究问题

这个项目可以发展出多个研究方向：

### 1. 不完全信息多智能体决策

问题：

```text
在隐藏配置、随机性和同时行动条件下，如何评估最佳策略？
```

可研究：

```text
POMDP、Belief State、Opponent Modeling、Multi-Agent RL
```

### 2. 可解释游戏 AI

问题：

```text
AI 如何不仅给出行动，还能解释风险、收益和博弈逻辑？
```

可研究：

```text
Explainable AI、decision trace、counterfactual explanation
```

### 3. 玩家风格建模

问题：

```text
如何从历史行为中识别玩家风险偏好、读换倾向和抗压能力？
```

可研究：

```text
Behavior Modeling、Clustering、Sequence Modeling、Bayesian Inference
```

### 4. 双打联合动作搜索

问题：

```text
在双打一回合极大的联合动作空间中，如何高效搜索？
```

可研究：

```text
MCTS、Beam Search、Action Pruning、Policy Prior
```

### 5. 配队推荐与元博弈

问题：

```text
如何根据环境流行趋势和玩家风格推荐队伍？
```

可研究：

```text
Meta-game Modeling、Combinatorial Optimization、Winrate Prediction
```

## 短期可展示 Demo

为了让项目尽快有展示效果，短期可以做一个小 demo。

### Demo 1：双打局面分析器

输入：

```text
我方 2 只宝可梦、对方 2 只宝可梦、天气、场地、可选行动
```

输出：

```text
- 推荐联合行动
- 对方可能行动
- 集火 / 守住 / 控速的风险收益
- 稳健解和激进解
```

### Demo 2：Replay 复盘器

输入：

```text
一场对战记录
```

输出：

```text
- 每回合局面变化
- 关键转折回合
- 可能的替代操作
- 胜率变化曲线
```

### Demo 3：玩家风格化建议

输入：

```text
同一个局面 + 不同玩家风格
```

输出：

```text
面对保守玩家建议 A
面对激进玩家建议 B
面对抗压差玩家建议 C
```

### Demo 4：队伍弱点与风格匹配

输入：

```text
一支双打队伍 + 玩家风格
```

输出：

```text
- 属性弱点
- 控速手段
- Protect / 联防资源
- 适合的操作风格
- 可能需要补强的位置
```

## 总结

这个项目的核心吸引力在于：它把一个大家熟悉的策略游戏，转化成了一个严肃且有趣的 AI 与博弈论问题。

```text
宝可梦对战规则复杂，适合做模拟器；
双打行动空间巨大，适合做博弈树搜索；
隐藏信息和随机性明显，适合做概率推断；
玩家风格影响显著，适合做行为建模；
Replay 数据丰富，适合做机器学习；
《宝可梦：冠军》可能带来新竞技环境，适合提前布局。
```

我们希望把它做成一个兼具学习价值、研究价值和实际使用价值的项目。欢迎感兴趣的老师和同学一起参与。
